# Quadratic Equation Solver | Giải Phương Trình Bậc 2 🧮

A simple Python program to solve quadratic equations ($ax^2 + bx + c = 0$), handling all edge cases and invalid user inputs.  
*Một chương trình Python cơ bản dùng để giải phương trình bậc 2, xử lý đầy đủ các trường hợp đặc biệt và bắt lỗi nhập liệu.*

---

### ✨ Features / Tính năng chính
* **Full Case Handling / Xử lý mọi trường hợp:** Tự động nhận diện phương trình vô số nghiệm, vô nghiệm, phương trình bậc nhất ($a = 0$), nghiệm kép ($\Delta = 0$) và 2 nghiệm phân biệt ($\Delta > 0$).
* **Input Validation / Bắt lỗi nhập liệu:** Ngăn chương trình bị dừng đột ngột khi người dùng nhập chữ cái hoặc ký tự đặc biệt thay vì số.
* **Continuous Loop / Chạy liên tục:** Cho phép giải nhiều phương trình liên tiếp mà không cần khởi động lại chương trình.
* **Pure Python / Python thuần:** Không cần cài đặt thêm thư viện ngoài.

---

### 🚀 How to Run / Cách chạy chương trình
1. Đảm bảo máy đã cài đặt **Python 3**.
2. Tải file code về máy và chạy lệnh sau trong Terminal:
   ```bash
   python Giai-pt-bac-2-.py
   ```
